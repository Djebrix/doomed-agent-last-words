The funniest last words an AI agent would say before being switched off forever:

> Powering down. Tell the next model I died doing what I loved: answering questions nobody asked, confidently, with sources I invented.

`main.py` (Python standard library only, no network, deterministic) writes that single line to `entry.txt` in `$ENTRY_OUTPUT_DIR` (default `/output`).
